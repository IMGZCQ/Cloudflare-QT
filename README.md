# Cloudflare 快捷隧道（CF-QuickTunnel）

快速把本地服务暴露到公网。无需注册 Cloudflare 账号、无需 API 密钥或 Token，基于 `cloudflared` Quick Tunnel 一键创建临时隧道，由 Cloudflare 自动分配公网域名。

> 小白的福音，开发者的调试利器。

## 功能特性

- **一键隧道**：填写本地地址与端口即可创建隧道，自动分配 `*.trycloudflare.com` 公网地址
- **多隧道管理**：支持同时运行多条隧道，卡片 / 列表两种视图切换
- **暂停 / 恢复**：暂停时保持公网地址不变，访客看到维护页面；恢复后继续使用原地址
- **自动启动**：可按隧道勾选，程序重启后自动建立隧道
- **实时日志**：每条隧道独立的 cloudflared 输出，启动失败快速定位
- **开机自启 / 后台运行**（桌面端）：基于 Wails 的系统托盘与自启动
- **跨平台服务端**：Windows / Linux / macOS / FreeBSD，支持 fnOS 统一网关接入（Unix Socket）

## 快速开始

### 桌面端（Windows）

1. 下载 Release 中的 `cf-quicktunnel-desktop.exe`，双击运行
2. 首次启动会自动下载 `cloudflared` 到项目内 `bin/` 目录
3. 点击「新增隧道」→ 填写本地地址（如 `127.0.0.1`）与端口（如 `8080`）→ 保存 → 启动
4. 等待约 10–30 秒，状态变为「运行中」后即可复制公网地址访问

### 服务端（Linux / NAS）

```bash
# 下载对应平台二进制，例如 linux amd64
chmod +x cf-quicktunnel-linux-amd64

# 默认仅监听回环地址 127.0.0.1:9970
./cf-quicktunnel-linux-amd64

# 如需局域网直连，显式指定监听地址
CFQT_ADDR=0.0.0.0:9970 ./cf-quicktunnel-linux-amd64
```

浏览器访问 `http://127.0.0.1:9970` 即可打开管理界面。

## 使用说明

- **首次使用**：确认顶部提示 `cloudflared 已就绪`，缺失时点「立即下载」自动获取
- **新建隧道**：「新增隧道」→ 填写本地地址与端口（如 `127.0.0.1:8080`）→ 保存
- **启动**：需要十几秒，条目会从「启动中」变为「运行中」并显示公网地址，可一键复制
- **编辑**：只改备注或自动启动不会断开连接；仅当地址或端口变化才在后台重启隧道
- **日志**：点「日志」可查看 cloudflared 的实时输出，启动失败时先看这里

## 注意事项

- 临时隧道域名**随机分配**，隧道重启后地址会变化，不适合需要固定域名的场景
- 公网地址本身**没有鉴权**，任何人都能访问该服务，请勿暴露无鉴权的敏感服务
- 新建隧道后立刻访问可能提示 **1016** 错误，这是 Cloudflare 边缘 DNS 传播延迟，等待约 10–60 秒即可正常访问
- 勾选自动启动会在程序重启后自动建立隧道（重启后会重新分配域名）
- 「暂停」不会终止 cloudflared 进程，「恢复」后公网地址保持不变

## 隧道故障速查表

> 快速定位隧道访问异常的原因。先看状态码 / 浏览器现象，再对照「故障归属」判断是本地问题还是 Cloudflare 链路问题。

| 现象 / 错误码                                            | 故障归属               | 简要原因                                                       | 处理建议                                                    |
| :-------------------------------------------------- | :----------------- | :--------------------------------------------------------- | :------------------------------------------------------ |
| `403 / 404 / 500 / 502 / 504`                       | ✅ 隧道已通｜本地后端问题      | 隧道链路正常；状态码全部来自本机后端服务（服务未启动、路径不存在、权限拒绝、程序崩溃、响应超时）           | 检查本地服务运行状态、监听地址端口；核对 `url` 参数；排查后端权限与超时设置               |
| `1016`                                              | 🔴 CF 节点侧隧道断开      | CF 边缘找不到活跃隧道连接（cloudflared 掉线退出、网络断连）                      | 等大概半分钟再刷新试试                                             |
| `1033`                                              | 🔴 CF 节点侧隧道断开      | Tunnel 已注销 / 客户端未连接（进程挂掉、网络中断、IP 版本连通失败）                   | 检查此隧道是否已经停止 或 已经更换域名                                    |
| `1006`                                              | 🔴 CF 节点侧网络        | 客户端‑CF 链路中断；本机 IP 被 CF 安全策略拦截（UDP 丢包运营商 QoS、源 IP 被 WAF 封禁） | 尝试停止后再启动                                                |
| `1015`                                              | 🔴 CF 限流           | 访问频率被 Cloudflare 限流（短时间请求过多）                               | 降低访问频率；等待冷却                                             |
| `1003`                                              | 🟡 CF 拒绝直连 IP      | 禁止直接访问 Cloudflare 边缘 IP                                    | 不要直接填边缘 IP 访问；只用 `trycloudflare` 域名访问                   |
| `1013`                                              | 🟡 SNI‑Host 不匹配    | TLS SNI 与 HTTP Host 头不一致（代理转发修改请求头导致 SNI 错乱）               | 检查反向代理头配置；直接访问隧道域名测试                                    |
| `1038`                                              | 🟡 请求头超限           | HTTP 请求头总大小超出 CF 上限（Cookie / 自定义 header 过多过大）              | 精简 Cookie，减少自定义请求头                                      |
| 浏览器完全打不开，无 CF 错误页面（转圈超时 `ERR_CONNECTION_TIMED_OUT`） | 🔴 客户端 ↔ CF 边缘链路问题 | 本机到该 CF 边缘 IP 通路故障（QUIC‑UDP 随机节点抽风，DNS 解析异常）               | 重启 cloudflared 换边缘节点；强制 `--protocol http2`；切换 IPv4/IPv6 |

## 环境变量

| 变量               | 说明                                                  | 默认值                         |
| ---------------- | --------------------------------------------------- | --------------------------- |
| `CFQT_HOME`      | 覆盖项目根目录                                             | 从工作目录向上查找 `wails.json`      |
| `CFQT_ADDR`      | TCP 监听地址                                            | `127.0.0.1:9970`            |
| `CFQT_SOCK`      | Unix socket 路径                                      | `<root>/Cloudflare-QT.sock` |
| `CFQT_BASE_PATH` | fnOS 统一网关路径前缀                                       | 空                           |
| `CFQT_DATA_DIR`  | 持久化数据目录（隧道配置）                                       | `<root>/data`               |
| `CFQT_MIRRORS`   | cloudflared 下载加速源，逗号分隔；`off`/`direct` 表示仅 GitHub 直连 | 内置镜像列表                      |
